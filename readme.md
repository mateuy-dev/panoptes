# Panoptes
I have an KMP deployed to google play, apple store, windows store and snap. They use the same sources and code numbers. 
I want to create an app (console for now) to manage the diferent published versions in production, alphas,...

Tecnologies:
- Use kotlin using KMP as much as possible.
- Use Ktor client
- Create a console UI using https://github.com/JakeWharton/mosaic
